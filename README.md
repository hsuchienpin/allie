# Allie's Playground

## Little Salon 美妝沙龍原型（2026-10-24）

首頁新增 Little Salon，或直接開啟 `salon/`。女生頭頸特寫提供口紅、眼影的自由筆觸、六色選擇、筆刷大小與雙眼同步；頭髮以 68 束獨立髮束呈現，可剪短側髮和瀏海，並用吹風機吹動。化妝自動放大臉部，美髮切換完整頭髮視角；吹風支援按住操作和持續吹風開關。

提供上一步／下一步、卸妝、恢復長髮、重新開始與 1200×1440 PNG 照片預覽及下載。進度獨立保存在同來源、同瀏覽器的 localStorage，不影響既有貼紙與紙娃娃收藏；沒有跨裝置同步。原型不發放貼紙。操作與範圍見 [docs/SALON.md](docs/SALON.md)。與紙娃娃工坊一併透過既有 GitHub Pages 流程更新至公開遊戲首頁。

## 紙娃娃工坊（2026-10-24）

新增 Paper Dolls 首頁入口，或直接開啟 `doll/`。提供 14 個訂製分類與 160 個選項、換色與花樣、復原／重做、隨機搭配、角色取名、收藏存檔、再次修改、另存、改名、複製與 PNG 下載。以有纖維紋理的紙張、膠帶與分層剪紙呈現。

公開試玩：[紙娃娃工坊](https://hsuchienpin.github.io/allie/doll/)，也可從遊戲首頁的 Paper Dolls 進入。獨立試玩站仍保留：[紙娃娃工坊獨立站](https://paper-doll-atelier.chienpin-hsu.chatgpt.site)（目前限擁有者帳號存取）。

角色保存於獨立的 IndexedDB，重開同一瀏覽器可接續最後創作；收藏只留在同一來源、裝置與瀏覽器，沒有雲端同步。清除網站資料會失去收藏。本機與線上試玩站的資料分開。詳細說明見 [docs/PAPER_DOLL.md](docs/PAPER_DOLL.md)。

所有頁面共用固定 Home／Full screen 操作列。外層畫面保留，遊戲在同來源內框切換，所以瀏覽器全螢幕不會因遊戲導覽而結束。直接遊戲網址與貼紙／草稿保存空間沿用原設定。

給 Allie 的獨角獸公主遊戲樂園。六個遊戲共用貼紙背包，英文操作、繁體中文說明；免登入，直接在瀏覽器遊玩。Piano／Drums 各有 10 首歌曲；遊玩畫面的 ← Songs 回到各自選曲首頁，音符與鼓點已加大。

## 保存方式

貼紙、音效偏好與草稿保存在同一來源、同一瀏覽器的 IndexedDB。貼紙扣除與草稿寫入使用同一交易；保存失敗不扣貼紙。Undo 移除貼紙時退回一張，Redo 再次使用同一張；移動、縮放、旋轉和下載作品不會退回或再次扣除。

同一任務重試只保存一張；多分頁操作會檢查草稿版本，拒絕覆蓋別的分頁已更新的作品。舊 Slice／Bowl 收藏每種已收集圖案各轉入一張，不推算過去取得的次數。

無法保存的瀏覽器仍可遊玩和下載作品，但不啟用會消耗庫存的貼紙操作。清除網站資料、無痕視窗關閉、換瀏覽器或裝置會失去當地資料，未提供帳號或雲端同步。舊本機網址的紀錄無法跨來源自動搬到 GitHub Pages。

## 本機預覽與驗證

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory wwwroot
node --test tests/*.test.cjs
```

開啟 http://127.0.0.1:8765/ 。也可使用 .NET 8 執行 `dotnet run` 提供靜態檔案。網站發布只需要 `wwwroot`，不需要伺服器資料庫或 .NET 主機。

瀏覽器驗證：安裝 Playwright 並準備 Chromium 後，執行 `node tests/browser.cjs`。`BASE_URL` 可指定公開網址或帶子路徑的預覽網址；測試會用隔離的瀏覽器資料驗證獎勵和保存，並把截圖放在忽略上傳的 `artifacts/browser`。

## GitHub Pages

`.github/workflows/pages.yml` 在 main 更新時檢查 JavaScript、執行邏輯測試，再部署 `wwwroot`。GitHub Pages 發布來源設定為 GitHub Actions。所有入口、圖片與 Worker 都支援 `/allie/` 子路徑。公開網址改名後沿用原有裝置保存空間，既有貼紙與草稿仍可讀取。

沒有圖片上傳、會員、外部 CDN、廣告或追蹤程式。自行匯入的照片和畫作在裝置處理；Ideas 只生成給家長複製的中文提示詞，不會呼叫 AI 或替使用者傳送照片。未實作離線重新開啟。
