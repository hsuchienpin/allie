# Little Salon 公主美妝沙龍

本機首頁選 Little Salon，或進入 `/salon/`。沿用固定 Home／Full screen 外層，可跨首頁保留全螢幕。介面以英文工具名稱搭配繁體中文提示。

## 操作

| 工具 | 玩法 |
| --- | --- |
| Lipstick | 選色後在嘴唇上拖動，顏色限制於嘴唇內；反覆塗抹疊色。 |
| Eyeshadow | 選色後在眼皮上刷色；左右同步預設開啟，取消勾選可各自塗色。眼睛維持張開，方便看到眼線與眼影一起搭配的效果。 |
| Eyeliner | 六色細筆沿上眼皮與眼尾描畫，範圍限制於眼線區；筆刷 2–14 px，可左右同步。 |
| Blush | 六色柔邊筆刷在兩頰畫畫，筆刷 20–70 px，可左右同步；每一筆均勻上色，多畫幾筆可疊色。 |
| Jewelry | 皇冠、髮飾、耳環、項鍊各三款，可同時配戴。點選「不戴」移除單一類，或「取下所有飾品」。 |
| Scissors | 在側邊長髮或瀏海上滑動。每束頭髮獨立變短，剪下的部分會掉落。 |
| Hair dryer | 先選 Straight 吹直、Inward 髮尾內彎、Outward 髮尾外翹或 Volume 蓬鬆，在髮束附近按住吹整，放開後保留造型。也可按 Turn on 持續造型，移動吹風機，再按 Finish 完成定型。 |

預設開啟飾品盒與完整公主頭頸造型。四種化妝工具自動切換臉部近景，飾品、剪髮與吹髮顯示完整頭髮。造型逐漸作用在附近髮束，可左右分開整理；髮根固定，剪短後仍能重新吹整。畫布採 Pointer Events、指標捕捉與 `touch-action: none`，設計上供滑鼠與單指拖曳；第二隻手指不會接手或取消第一隻手指的操作。取消觸控、視窗失焦或旋轉造成畫布尺寸改變時，未完成的手指操作會回復到操作前；持續造型開關則會停止並保留當次成果。

Undo／Redo 可還原妝容、剪髮、造型與飾品；一次按住吹整或一次 Turn on → Finish 算一步，包含當次處理的全部髮束。Reset styling 只清除造型，保留髮長和妝容；Grow hair back 恢復原始長髮與造型；Remove makeup 只卸妝，保留髮型和飾品。取下所有飾品會保留妝容和髮型。Start over 全部重設，當次仍可用 Undo 回復。Save photo 開啟 1200×1440 PNG 成品預覽，再按 Download PNG；也可長按成品儲存。照片顯示完整定型髮型，不含工具游標和瞬間風力擺動。

## 保存與範圍

進度沿用 `allie-little-salon-v1` 的 localStorage，資料格式升為 version 3，保存四種妝容筆觸、髮束長度、每束的定型形狀與四類飾品。舊 version 1／2 自動帶入原妝容與剪髮；version 2 保留已有定型資料。新存檔與舊檔初次升級預設配戴水晶皇冠。只有已完成的操作才會寫入，未完成或取消的吹整不會被自動保存。瞬間風力擺動、所選工具與復原歷史不跨重整保存。只保留最後一個造型，同來源與瀏覽器重新開啟可繼續。清除網站資料或使用無痕模式可能失去進度；不提供帳號、雲端同步、作品上傳或貼紙獎勵。無法保存時會顯示提示，仍可遊玩與產生照片。

本版只有一位原創公主風插畫女生的頭部與頸部，香檳金髮、紫色寶石眼睛與柔和的玫瑰色妝容。鏡面、工具圖示、首頁封面、網站圖示及飾品均使用本機向量繪圖，無外部圖片或字型依賴。頭髮是 68 束二維彈性髮束，頭頂有固定髮根；可剪側髮和瀏海，不是每一根髮絲的寫實模擬。仍維持單一角色；飾品固定於頭部、髮側、耳垂或頸部，換髮型後可自由取下搭配。

## 檔案

- `wwwroot/salon/core.js`：髮束幾何、剪髮判定、風力與彈性、保存資料驗證、復原歷史。
- `wwwroot/salon/art.js`：12 款飾品的共用向量圖形，同時用於人物配戴與選單預覽。
- `wwwroot/salon/renderer.js`：插畫、妝容遮罩、柔邊筆刷、髮束和剪落動畫。
- `wwwroot/salon/app.js`：工具、指標輸入、近景座標、保存與成品照片。
- `tests/salon.test.cjs`：剪髮、四種造型、左右分開、定型持久、剪曲髮後重塑、風力穩定、存檔遷移與座標映射。
- `tests/salon-input.test.cjs`：實際控制程式的手指放開、持續造型、復原／重做、取消觸控、第二隻手指、未完成操作的保存隔離與返回首頁保存。

測試紀錄見 `TESTING.md`。本機試玩使用 `python -m http.server 8771 --bind 127.0.0.1 --directory wwwroot`，網址為 `http://127.0.0.1:8771/`；此網址供目前這台電腦使用。公開試玩網址為 https://hsuchienpin.github.io/allie/salon/ ，也可從線上遊戲首頁第一個 Little Salon 入口進入。
