## 保存方式

使用獨立 IndexedDB `paper-doll-workshop-v1`；`characters` 保存全部選項、顏色、花樣及名字，`drafts` 保存最後工作草稿。正式角色寫入成功才顯示成功訊息。更新與刪除以交易檢查版本，避免其他分頁的新修改被舊資料覆蓋；衝突時保留當前畫面並提示另存新角色。沒有帳號或雲端同步。

存檔限定同一來源、同一瀏覽器、同一裝置。清除網站資料會失去收藏；本機與獨立線上試玩站的收藏不會互通。無法使用 IndexedDB 時可搭配與下載圖片，停用角色存檔與收藏冊。PNG 僅含角色與名字，全部在裝置內產生。

## 本機試玩

```powershell
python -m http.server 8773 --bind 0.0.0.0 --directory wwwroot
```

電腦開啟 `http://127.0.0.1:8773/doll/`。同區網平板使用電腦的區網位址及相同連接埠；須能通過電腦現有防火牆規則。也可直接部署靜態檔案，不需要後端資料庫。

## 原始碼

- `catalog.js`：材料庫與色票。
- `core.js`：選項、名稱與復原／重做。
- `renderer.js`：全部角色材料與 SVG 繪圖。
- `storage.js`：IndexedDB 交易、版本檢查與草稿。
- `app.js`：工作桌、取名、收藏冊與下載。
- `style.css`：紙張風格與響應式畫面。

獨立 Sites 試玩站的設定放在 `sites/paper-doll-workshop/.openai/hosting.json`。打包時以 `wwwroot/doll/` 作為來源，複製到該目錄的 `dist/`。
