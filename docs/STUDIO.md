# Draw

詳見 [遊玩說明](PLAY_GUIDE.md)。10 張不分難度的著色紙、36 色、三種筆刷、填色、免費印章與共用獎勵貼紙，支援圖片匯入、PNG／JPG 下載及大畫布模式。

筆畫保留在底層，黑線在上層；一次性貼紙另以可調整的圖層顯示。底色、黑線、貼紙位置與扣除庫存一起保存於 IndexedDB。最多復原／重做最近八步；Undo 移除貼紙會退款，Redo 會再次扣除同一張，新筆畫會清空重做紀錄。Paper 選單的 Clear 只清顏色。常駐色盤與工具列不需先離開畫布；Paper、Sticker、Stamps、Brush 分開打開，手機色盤可左右滑動。

`shared/studio.js` 負責貼紙、草稿和匯出合成；`js/app.js` 保留繪圖和匯入操作；`js/engine.js`／Worker 保留填色及線稿處理。匯入圖片只在裝置處理，不會呼叫 AI。

圖庫保留原本的獨角獸，其餘九張重新繪製成相近複雜度、寬闊封閉區域。已移除圖庫、匯入及提示詞工具的難度選擇。新圖使用獨立草稿 ID，避免覆蓋舊圖的線稿、顏色或貼紙；最後使用的舊草稿仍可恢復。左上角 Home 可回首頁，已有畫作時先提示保存。
